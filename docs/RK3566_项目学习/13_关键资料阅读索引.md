# 13 关键资料阅读索引

先按问题选资料，再沿“生产者 → 数据或资源 → 消费者”阅读。本章链接相对于学习目录，节点、函数和成员名称用于稳定定位；行号只是当前文件的辅助位置。

## 13.1 按当前问题选择入口

| 要解释的问题 | 先读 | 再连接 |
| --- | --- | --- |
| 一根 GPIO 怎样控制器件 | 对应底板原理图的连接器、网络与开关电路 | pinctrl、GPIO 属性、驱动 API |
| 某节点怎样进入驱动 | 基础 DTS、产品 overlay | 总线创建、匹配表、probe 和属性读取 |
| 画面或亮度怎样形成 | 面板规格、命令表、显示端点和背光节点 | panel-simple、DSI、pwm_bl 及电路 |
| 触点为什么变成这个坐标 | 当前分支的帧布局、CFG 与采集函数 | 驱动变换、input 能力及桌面映射 |
| 电量为何停住或状态不同步 | CW2015 周期任务与属性回调 | I2C 返回、缓存、gpio-charger 与供电关系 |
| 温度如何改变风扇 | zone、trip、map 和运行 policy | governor、pwm-fan、PWM 与负载 |
| 安装包改了什么 | 确定哈希的包、control 和 data 成员 | hooks、系统文件、启动选择与最终树 |

## 13.7 只读检查包成员的方法

已有 Debian/Ubuntu 环境中，从项目根目录使用下列命令读取包。先列出成员名称，再按准确名称输出内容；控制脚本只按文本阅读。

```sh
# 包内部身份与依赖。
dpkg-deb --field debs/radxa-overlays-dkms_pwm.deb Package Version Architecture Depends

# 找到基础树与风扇模块的实际成员路径。
dpkg-deb --contents debs/linux-image-6.1.84-12-rk2410-nocsf_6.1.84-12_arm64.deb |
    grep -E 'rk3566-radxa-cm3-io.dtb|pwm-fan.ko'

# -xO 将数据档案里的一个成员送到终端，不安装到系统。
dpkg-deb --fsys-tarfile debs/linux-image-6.1.84-12-rk2410-nocsf_6.1.84-12_arm64.deb |
    tar -xOf - ./boot/config-6.1.84-12-rk2410-nocsf |
    grep -E 'CONFIG_(TOUCHSCREEN_GT9XX|SENSORS_PWM_FAN|CHROME_PLATFORMS|THERMAL_DEFAULT_GOV)'
```

没有匹配输出时先看上游命令是否报告路径或成员错误，再判断配置是否缺失。参数含义见 [Debian dpkg-deb 手册](https://manpages.debian.org/bookworm/dpkg/dpkg-deb.1.en.html)。包内成员始终通过包文件定位，临时解包目录不作为长期文档入口。
