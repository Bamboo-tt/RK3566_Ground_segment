# RK3566 地面站板级适配学习指南

这套文档解释怎样让 CM3 与自定义底板上的器件成为 Linux 可用的设备，并沿一次显示配置、触摸事件、电量更新或风扇调速追到最终行为。

```text
CM3 控制器与底板接线、供电
    -> 设备树描述资源与连接
    -> 驱动匹配、取得资源、初始化器件
    -> 各条运行链并行工作
       +-- 显示与背光 -> 画面和照明
       +-- 触摸 -> input/evdev -> 用户态输入
       +-- 电池与外部输入 -> power_supply -> 状态读取
       +-- 温控 -> cooling device/PWM -> 风扇响应
```

## 学习对象与阅读起点

本仓库保存 Radxa CM3/RK3566 的设备树、两套 GT9XX 代码、Debian 交付包、屏幕资料、原理图和历史构建记录。完整 BSP 工程、最终 RootFS 镜像和地面站应用源码未随仓库提供，因此全书讲到标准接口及上层消费位置；图传、遥测、ROS、QGC 和飞控业务不在这套源码讲解范围内。

目标读者已有基础 C/C++、嵌入式 Linux、GPIO 和常见总线知识。正文在首次需要时解释 DTS 引用、驱动生命周期、输入帧、PWM 映射及 thermal 策略等概念，并立即对应当前材料中的节点、函数和数据。

先区分三个过程：构建把源码与配置变成文件；启动初始化建立资源与接口；运行处理事件和控制请求。内核、overlay 与 RootFS 可独立准备，多个外设也会并行运行。章节的阅读顺序帮助理解这些关系。

## 资料版本怎样配套

6 英寸与 7 英寸屏、地面站与相机底板、两套 GT9XX、基础 DTS 与包内 DTB、普通与 PWM overlay 包分别保留身份。正文在使用它们时交代对象，详细定位集中在第 13 章。

内核机制补充采用历史构建记录指定的 Radxa 提交 `3bbac32c942f4d98fc87bde3852f185dce56ff56`；公开打包仓库的 `6.1.84-12` 标签也指向该内核基线。Word 随后记录了 CM3 移植与本地修改，因而正文分别引用公开实现、本地供应商源码及包内产物，不将三者混成一个版本。

板端命令集中在第 10、11 章，作为目标 Linux 系统已有工具的检查方法；全书命令不附预设运行输出。原始资料入口还包括[全局架构与技术剖析](../../全局架构与技术剖析.md)。维护者使用根 [AGENTS.md](../../AGENTS.md) 引用的统一 [document-writing Skill](../../.agents/skills/document-writing/SKILL.md)，修订情况见[_authoring/工作记录.md](_authoring/工作记录.md)。
